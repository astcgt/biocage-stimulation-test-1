# Biocage stimulation test 1

PLCL (Corbion PURASORB PLC 8516, 85:15) contour-matched cages for pig C3/C4 holding a tissue-engineered biodisc.
Two designs: smooth and shoe-tread textured. FEM tests: vertical compression, ASTM F2077-style cyclic
compression (damage + cycle-jump), 6-DOF (100 N preload + escalating moments/shear).
Endpoints: damaged cage volume >15% (10%/20% also reported) or slip >2 mm vs C4.

Background: Lintz 2021 (Cornell) PhD thesis, ch.4 — PLA cages failed posteriorly because of a vertebral bony process.
